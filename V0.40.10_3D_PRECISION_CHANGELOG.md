# NEUL v0.40.10 — 3D Precision + Non-Regression

## 3D interaction is locked as a release requirement

- Keeps the existing movable native WebGL2 venue renderer.
- Keeps mouse/pointer drag rotation, wheel zoom and touch/pinch handling.
- Keeps the three separate canvases: venue overview, seat preview and full-screen 3D viewer.
- Canvas fallback remains only for devices that truly cannot create WebGL2; it is not the primary experience.

## Distance / seat precision

- Main-stage distance now uses the nearest stage edge/surface point instead of centre-only distance.
- Runway, B-stage and extra stage pieces can contribute their own nearest-distance result when present in the verified layout.
- Seat number changes lateral position within the selected row/section.
- Row changes section depth/rise and therefore camera position, viewing angle and distance.
- Existing venue/reference `metersPerUnit` calibration and explicit uncertainty remain visible instead of pretending centimetre accuracy.

## View / obstruction precision

- Adds stage-relative viewing direction classification and elevation/depression angle.
- Known rails, overhangs, fixed equipment and crowd proxies are tested against the current seat-to-stage sightline before an obstruction warning is shown.
- A known object that does not cross the sightline is reported as avoided, rather than automatically flagged.
- No new unverified pillars/towers are generated; aespa official-geometry protections remain.

## Reliability

- Restores the missing `offlineState()` function in `enhancements.js`, removing the prior page-level exception.
- Bumps the automatic 3D pipeline revision to `0.40.10-mainstream12-3dprecision.1`.
- Bumps the service-worker cache namespace so existing installations receive the updated renderer/UI assets.
- Adds `scripts/check-v0411.mjs` and browser-level WebGL regression evidence in `TEST_REPORT_v0.40.10-3DPrecision.md`.

## Preserved behavior

- 12 retained 3D venues stay unchanged as the resource policy.
- Full concert coverage reconciliation stays enabled.
- Ended events leave Upcoming/active 3D selection automatically.
- Archive remains capped at the 20 most recent ended events.
- News remains the last main content section and mobile News navigation remains intact.
