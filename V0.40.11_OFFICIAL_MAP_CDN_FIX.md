# NEUL v0.40.11 — Official Map CDN Display Fix

## Fix
- Fixed the official-map preview path that could report "source found but image unavailable" even when the promoter page exposed a valid image.
- Added Live Nation International's official image CDN (`networksites.livenationinternational.com`) to the trusted official-image resolver.
- Added `場域圖` to official map-image candidate scoring.
- The browser now proxies the explicit display image first instead of re-resolving a different analysis/archive source.
- Server-side requests to Live Nation's CDN use the Live Nation Taiwan page as the Referer.
- aespa Taipei Dome reference now displays the Live Nation Taiwan official field map while retaining the separately calibrated 001–014 3D geometry data.
- Service-worker cache version bumped so a redeploy does not keep the old map-loader code.

## Unchanged
- Interactive WebGL2 3D remains the primary venue view.
- 12 retained 3D venues, concert coverage, Archive 20, News layout, TICC topology guard, and aespa no-invented-obstruction guard are unchanged.
