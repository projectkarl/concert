# NEUL v0.40.13 — Verified 316 Discovery + Recent Data Cleanup

- twconcertview public calendar is used as a 316-show candidate coverage reference (2026-09-22), never as an automatic official truth source.
- Discovery now fetches the root calendar first. If >=90% of the advertised count is parsed, the expensive month sweep is skipped; month-by-month scanning runs only when coverage is insufficient.
- A last-healthy discovery snapshot can recover an unusually thin Vercel crawl. The snapshot stores upcoming events only, never ended/archive events, and is capped at 420 records.
- Official ticket/promoter/artist/venue sources still override coverage-only candidates during merge and dedupe.
- Entertainment News now sorts newest to oldest and hard-filters to the most recent 7 days.
- News renders 8 stories initially and exposes “看更多新聞” in 8-story increments, with a 24-story recent-data cap.
- Archive remains capped at the 20 most recently ended events; Upcoming cache does not retain expired events.
- Service Worker cache key updated so deployed clients receive the new news/discovery logic immediately.
