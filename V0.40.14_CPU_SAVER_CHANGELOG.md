# NEUL v0.40.14 — Vercel CPU Saver

Base: v0.40.13 Verified316 RecentData. UI and 3D visual design are unchanged.

## CPU reductions

- `/api/events`: shared CDN cache increased from 1 hour to 6 hours; next-update metadata matches the 6-hour cadence.
- `/api/official`: shared CDN cache and rotation bucket increased from 1 hour to 6 hours.
- `/api/refresh` and `/api/coverage`: removed `Date.now()` query cache-busting so internal warm/status calls reuse the same shared cache keys.
- `/api/seat-map-image`: both successful images and “not found yet” results are cached for 6 hours, preventing repeated recursive page/image resolution.
- Browser event refresh now runs every 6 hours instead of hourly and only revalidates after tab return when data is stale.
- Seat-map OCR/Vision hydration is lazy: home load checks at most one stale event in the background; opening an event prioritizes that event.
- Background seat-map analysis tries one source; interactive event detail can try up to three official/ticket sources.
- Per-device seat-map success/miss checks are timestamped; unchanged sources are not retried for 24 hours in background or 6 hours interactively.
- Entertainment-news RSS cache increased from 15 minutes to 1 hour.

## Preserved

- Verified316 discovery and recent-data cleanup.
- Existing UI, responsive layout, Archive 20, Featured rotation, event/detail flows.
- Existing venue geometry, event-specific 3D, official-map OCR/Vision and Section Mapping capability.
- Daily Vercel cron remains; it now reuses the normal shared API cache instead of forcing unique cache-busting requests.
