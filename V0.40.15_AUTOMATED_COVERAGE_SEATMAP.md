# NEUL v0.40.15 — Automated Coverage + Official Map Recovery

Date: 2026-09-23

## Concert coverage
- Separates unique event records from external performance/showing reference counts.
- Reads the current advertised showing reference dynamically; no fixed 315/316 total is treated as truth.
- Sweeps Traditional-Chinese month pages first. English month pages run only when the zh-TW showing coverage remains below the reconciliation threshold.
- Coverage completeness is calculated showing-to-showing; the deduplicated event list is reported separately.
- Keeps official ticket/promoter/artist/venue sources authoritative over coverage-only candidates.

## Automatic official backfill
- Every `/api/events` sync rotates through up to 8 upcoming newly discovered official-ticket events that still lack a seat map.
- Successful official checks can automatically add seat-map URLs, section prices, sale time and ticket status without promoting the event into the hand-maintained seed set first.
- The existing hourly active-session refresh and daily Vercel warm-up remain in place.

## Official seat-map recovery
- The browser sends a bounded fallback list of official ticket/promoter/map candidates to the same-origin image resolver.
- `/api/seat-map-image` tries those official candidates sequentially; one stale CDN URL no longer makes the whole preview fail.
- Existing allow-list, HTTPS requirement, venue/event hint scoring and content-type checks remain enforced.

## UI count wording
- Upcoming list displays `活動 … 筆` for deduplicated records.
- The public calendar reference is labeled separately as `場次參考 … 場`.
