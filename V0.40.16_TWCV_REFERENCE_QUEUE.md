# NEUL v0.40.16 — twconcertview Reference Queue

Date: 2026-09-23

## Coverage reference ingestion

- twconcertview is now an explicit discovery/reference queue, not only a headline-count benchmark.
- Parsed unmatched rows enter the full NEUL list as `referenceOnly: true` with `參考收錄 · 待官方覆核`.
- When an official ticket/promoter/artist/venue source later matches the same event, merge priority automatically promotes the row and clears `referenceOnly`.
- twconcertview provenance remains in `sourceRefs` after promotion for auditability.
- Duplicate same-date/title/venue rows contribute to `referenceOccurrenceCount` while the visible activity list stays deduplicated.

## Serverless-safe automation

- Traditional-Chinese root calendar remains the primary fast path.
- If the root is thin, each sync scans a rolling batch of six Traditional-Chinese month pages instead of crawling the full 19-month horizon in one request.
- Vercel Blob upcoming snapshots accumulate those batches over successive syncs.
- English monthly pages are availability fallback only when the current Traditional-Chinese batch is completely unavailable; the smaller English inventory never replaces the Traditional-Chinese reference target.

## UI / telemetry

- Event result metadata separates deduplicated activity records, external showing reference count, and pending reference-queue rows.
- Reference-only event badges read `參考待核對`.
- `/api/events` exposes parsed/pending/promoted reference-queue telemetry.
- `/api/refresh` exposes the same queue status for automated warm-up monitoring.
