# NEUL v0.40.17 — Expanded Auto Coverage

Date: 2026-09-24

## Why this release exists

v0.40.16 could still fall back to about 83 upcoming seed records when the twconcertview crawl redirected to the smaller English calendar, timed out, or could not persist its rolling snapshot. That made the public list look substantially thinner than current Taiwan live-event indexes.

## Changes

- Added Artists.tw as a second discovery-only live-music reference index. It never overrides official ticket/promoter/artist/venue data.
- Prefer the public iCalendar feed for broad discovery; fall back to the current HTML index and bounded pagination when the feed is unavailable or thin.
- Added a dated, reference-only recent-event bootstrap so a cold/offline deployment no longer collapses to the old ~83 upcoming records.
- Offline/current fallback now has more than 120 upcoming rows before any live discovery runs.
- Fixed twconcertview locale redirect detection. If the zh-TW URL resolves to `/en/calendar`, NEUL no longer mistakes that response for a complete Traditional-Chinese inventory.
- A time-bounded, last-verified zh-TW reference floor (317 shows, checked 2026-09-24) is used only for coverage health when that locale redirect occurs; it does not invent event rows.
- UI separates deduplicated NEUL activity rows, TWCV showing reference, Artists.tw live-music index reference, and pending official-verification rows.
- Both community indexes are low-priority reference sources. Matching official records automatically promote/merge them while retaining provenance.
- Service-worker cache bumped to v0.40.17 and the new reference bootstrap is included in the app shell.

## Accuracy policy

Reference indexes are for omission detection only. Ticket prices, sale status, official seat maps, venue geometry and event-specific 3D remain governed by official ticketing, promoter, artist and venue sources.
