# NEUL v0.40.2 UX.3 Changelog

## Entertainment News
- Fixed page-grid integration (`news news`) so the section no longer auto-flows into a broken column.
- Restyled the section using NEUL's existing dark/light card system, typography, borders, pills, spacing and mobile behavior.
- Kept Korean news as default with Taiwan / US-Europe / Other tabs and keyword search.

## Selective 3D policy
- Added `shouldGenerateEvent3D()`.
- Known calibrated venues remain eligible, including stadiums such as Kaohsiung National Stadium.
- Temporary outdoor/ad-hoc venues such as plazas, parks, recreation grounds, beaches and open fields no longer generate fabricated seat 3D.
- Events are still retained in event lists, calendars and source tracking.

## Jason Mraz
- Corrected the event to use a dedicated `nangang-exhibition-hall1-4f` model.
- Replaced generic arena/bowl assumptions with a flat exhibition-hall baseline.
- Official event-page map can later override the structural draft through OCR/Vision.

## Official map display
- The preview renderer now sends an official event/ticket page directly to `/api/seat-map-image` even when a pre-resolved image URL is not yet stored.
- Added official promoter / artist / venue hosts to the trusted resolver start-page list.
- A generic image filename can still be recognized from nearby official copy such as `場地示意圖`.
- Official map remains below the sightline preview explanation.
