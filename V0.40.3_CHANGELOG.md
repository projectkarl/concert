# NEUL v0.40.3 — Official Seat Map + Physical Aisles

Base: NEUL v0.40.2. Website design is retained; changes are limited to functionality inside the existing VENUE 3D area.

## Added

- Displays the current event's official seating map directly below the existing 3D seat preview.
- Uses the existing same-origin `/api/seat-map-image` resolver, so ticket detail pages can resolve to the actual official seating-map image without opening another site.
- Shows source label and OCR/Vision mapping status.
- When OCR/Vision has reliable coordinates, the selected 3D section is marked on the official map.
- Clicking close to a recognized official-map section switches the existing 3D selector to the matching section.
- Hand-calibrated event layouts keep their verified geometry; OCR tokens are used only for image-to-section linkage unless the existing auto-regeneration rules allow geometry replacement.

## 3D aisle refinement

- Seating samples now leave real empty circulation lanes instead of drawing aisle guide lines over chairs.
- Bowl sections receive physical sloped side-aisle slabs and a physical cross-aisle slab for deeper sections.
- Floor seated blocks receive raised side walkway strips and a cross aisle where section depth warrants it.
- Selected bowl sections receive denser stair/riser detail and physical rail posts.
- Walkway surfaces stay light in both dark and light themes; the already-light venue ground remains unchanged.
- Standing-only and structural-only zones do not fabricate chair aisles.

## Scope / accuracy rule

Aisle geometry follows the verified section envelope and row depth. It is a physical 3D circulation model, not a claim that every stair/aisle width is centimeter-accurate unless the event/venue source provides that information. Official event maps continue to be the source of truth for ticket-zone boundaries.
