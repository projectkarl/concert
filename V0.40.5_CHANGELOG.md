# NEUL v0.40.5 — Every Event Custom 3D Audit

- Added strict event-specific 3D QA gate for every current event.
- Added missing venue baselines for compact halls, live houses, exhibition space and outdoor fields.
- Every current seed event now resolves to a unique event-specific layout instead of falling back directly to a base venue layout.
- Added explicit customization metadata: `eventSpecific3D`, `customizationLevel`, `qaGate`.
- Official-seat-map events continue to use OCR/Vision refinement.
- Venue-derived drafts remain marked for review until official seat maps are found.
- Added future unknown-venue runtime fallback so newly discovered events do not lose 3D coverage.
- Preserved the v0.40 visual design; `index.html` and `styles.css` unchanged.
