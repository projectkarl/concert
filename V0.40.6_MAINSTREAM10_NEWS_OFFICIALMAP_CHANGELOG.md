# NEUL v0.40.6 — Mainstream 10 / News Bottom / Official Map Preview

## UI
- Desktop navigation: `Planner` → `News`, linking directly to `#entertainmentNews`.
- Removed the old `#planner` anchor from Featured Concert so desktop News can no longer jump to the wrong block.
- Entertainment News remains the final content section immediately before the footer.
- Every K-star reference layout uses one consistent dropdown suffix: `· 範例` (including IVE).

## Official map preview fix
Root cause: the preview previously returned `null` unless the selected layout had an `eventId` and a matching current event. Most K-star reference layouts are historical/reference scenes, so the panel stayed hidden even with an official source.

Fixes:
- K-star reference layouts now build a lightweight source record when no current `eventId` exists.
- The image proxy receives `venue`, `venueId`, and `event` hints for candidate disambiguation.
- Added official venue hosts needed by the 10 reference venues to the allowlist (e.g. TICC, NTSU, TAINEX, Zepp, Farglory Dome, KCG/KPH).
- Direct official image fallback remains enabled when a real image URL is available.
- If an official page currently exposes no parsable image, NEUL keeps the source link and verified 3D instead of substituting a non-official graphic.
