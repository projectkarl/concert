# NEUL v0.40.8 — Automatic Ticket / Concert Lifecycle

## Scope
Website design remains locked to the v0.40 line. `index.html` and `styles.css` are unchanged from v0.40.7. This release changes source verification, countdown logic, lifecycle switching, Archive/3D behavior and Featured rotation only.

## Automatic source verification
- `/api/events` CDN freshness: 1 hour (`s-maxage=3600`, stale revalidation retained).
- `/api/official` official-page verification: 1 hour.
- Open pages automatically call the merged event feed every hour.
- Returning to a tab whose feed is at least one hour old triggers a refresh.
- Existing daily `/api/refresh` cron remains as a no-traffic fallback.
- A failed background refresh preserves the last verified in-memory event set instead of replacing it with older seed data.

## Ticket lifecycle
The frontend now calculates official ticket milestones separately from the concert date:

1. Future official sale milestone → `搶票倒數`.
2. Sale milestone has started and it is still the same Taiwan calendar day → `今日開賣`.
3. If another official sale milestone remains (for example presale → general sale), countdown advances to that next milestone.
4. After all known sale days have ended → concert/show countdown.
5. Concert start → `演出進行中`.
6. Effective end time passes → Archive.

`generalSale` is preferred when it is the only canonical sale date, while `ticketTimeline` can supply earlier official presale/member sale milestones.

## Sale-date extraction
Official ticket discovery/monitoring recognizes variants including:
- 一般售票 / 正式售票 / 公開售票
- 全面開賣 / 全面啟售
- 開賣日期 / 開賣時間 / 啟售時間 / 啟售
- General Sale / Public Sale / On-Sale
- Full-year and same-year short dates
- 24-hour clock, AM/PM (including `12PM`), and Chinese 上午/中午/下午/晚上 forms

Ticket-page monitor URLs now include `sourceUrl`, `ticketUrl`, `ticketSourceUrl` and `secondarySourceUrl`.

## Archive + 3D selector
- Lifecycle is recalculated every minute while the page is open.
- Ended events automatically leave Upcoming and enter Archive without reload.
- Ended event-specific layouts are removed from the 3D concert selector.
- If the selected 3D event ends, the selector moves to the next upcoming event at the same venue; if none exists it returns to the venue base layout.

## Featured
- Featured keeps the existing design.
- Rotation remains exactly 10 seconds.
- Pool expanded from 5 to up to 10 non-ended Taiwan events.
- Ended events automatically leave the Featured pool.

## Data calendar
Daily concert calendar rows now also show the current lifecycle badge (`搶票…`, `今日開賣`, `已開賣`, etc.) alongside 3D verification status.
