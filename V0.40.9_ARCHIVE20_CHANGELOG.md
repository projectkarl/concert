# NEUL v0.40.9 · Archive 20 lifecycle update

- Kept the existing automatic event refresh pipeline: page refresh validation about hourly plus Vercel daily scheduled refresh.
- Event-specific 3D generation remains automatic only for the retained calibrated venue set. Unsupported venues stay listing-only.
- Ended events automatically leave Upcoming and the live event-specific 3D layout selector.
- Added a hard Archive retention cap of 20 most recently ended events in both `/api/events` and the browser fallback path.
- The lifecycle timer compacts the Archive every minute, so the 21st oldest ended event is removed when a new event rolls into Archive.
- Added API metadata: `archiveLimit` and `archiveCount`.
- Archive tab now displays `Archive · 20`.
- Venue K-star reference examples remain separate calibration assets and do not consume the rolling Archive quota.
