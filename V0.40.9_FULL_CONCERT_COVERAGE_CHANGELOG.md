# NEUL v0.40.9 — Full Concert Coverage Reconciliation

Date: 2026-09-21

## Concert-list completeness

- Replaced the old one-page `twconcertview` coverage parser with a month-by-month sweep spanning the recent month through the next 18 months.
- Deduplicates month pages by date + title + venue and exposes parsed count vs the source's advertised upcoming-show count.
- Full activity modal retains every discovered Taiwan concert after deduplication. The homepage remains a compact first-10 preview by design.
- Official promoter, ticketing, artist, and venue sources remain authoritative and can overwrite coverage-only records with confirmed details.
- Added filters for non-performance products such as fan buses, shuttle products, merchandise, and sports-ticket pages.
- Added identity normalization so ticket-product wrappers do not multiply the same performance into several rows.

## aespa Taipei Dome correctness guard

- Keeps official floor blocks 001–014.
- Removes unverified generic vertical support towers / side speaker arrays.
- No unverified runway or B-stage is generated for the reference layout.
- Official map preview is allowed for reference layouts without a current `eventId`.
- If an official host prevents embedding, the UI may use a verified archive of the same seating graphic; it must not substitute a third-party fan-made diagram as “official”.

## Coverage telemetry

`/api/events` now exposes:

- `coverageReferenceCount`
- `coverageReferenceParsedCount`
- `coverageReferenceRatio`
- `coverageReferenceComplete`
- `coverageReferenceMonthsScanned`
- `coverageReferenceSuccessfulPages`

The frontend displays this reconciliation beside the event-list status so an incomplete crawl is visible instead of silently appearing complete.
